# B2B-marketing-website

# Be the Buzz

A responsive marketing website for a B2B growth strategy agency, built with HTML, CSS, and vanilla JavaScript.

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

## Project Structure

- `index.html` contains the page markup.
- `src/style.css` contains the layout, typography, and animations.
- `src/main.js` controls the interactive service cards.
- `public/` contains images, fonts, and the logo used by the page.
